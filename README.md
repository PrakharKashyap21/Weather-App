# 🌤️ Weather App

A simple and user-friendly weather application that provides real-time weather information for a selected location using a Weather API.

## 🚀 Features

- 🌍 Search weather information by city
- 🌡️ Get current temperature
- 💧 View humidity information
- 💨 Check wind speed
- ☁️ View current weather conditions
- 🔄 Fetch real-time weather data through API integration
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

- Python
- Weather API
- API Integration
- Requests
- Python-based application interface
